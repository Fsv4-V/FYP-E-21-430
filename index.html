Project overview

What this project is about

Clinical need

Diabetic wounds require regular monitoring because infection and delayed healing can happen between clinical visits. Wound pH, temperature and moisture give useful early information about healing condition.

Technical idea

The patch uses a flexible sensing layer with PANI pH sensing, TMP117 temperature measurement and embedded electronics to convert sensor readings into usable digital data.

Main target

The aim is to create a low-cost, compact and practical wound monitoring prototype that can be developed using accessible university laboratory methods and documented weekly progress.

Design limitations

Limitations and improvement points

This section uses stronger colors for clear visibility.

Calibration accuracy

The PANI pH sensor must be calibrated using standard buffer solutions before reliable wound testing.

Clinical validation

The prototype is not a clinical medical device yet. Real wound testing requires ethical approval and medical supervision.

Flexible packaging

The final patch needs safe encapsulation so electronics are protected while the sensing region remains exposed to wound fluid.
