Smart Diabetic Wound Monitoring Patch

A flexible wound monitoring system using a PANI pH electrode, Ag/AgCl reference electrode, TMP117 temperature sensor, moisture sensing, and wireless data communication for real-time chronic wound assessment.

Project Overview

Clear, low-cost and wearable wound monitoring concept

The project focuses on a smart diabetic wound patch that can monitor important wound conditions without repeatedly removing the dressing. The main sensing parameter is pH, supported by temperature and moisture information.

pH Monitoring

PANI-based potentiometric pH sensing is used to identify changes between healing and infected wound conditions.

Temperature

TMP117 is used as the selected temperature sensor for accurate digital temperature monitoring.

Wireless System

ESP32-S3 and BLE communication are used for compact, low-power wireless monitoring.
